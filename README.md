# Node.js Приложение для управления магазином электросамокатов, скейтбордов и запчастей

Приложение для управления каталогом продуктов магазина с использованием файловой системы, потоков и worker threads.

## Структура проекта

```
Sv4_labs/
├── src/
│   ├── fs/              # Операции с файловой системой
│   │   ├── create.js    # Создание новой записи
│   │   ├── copy.js      # Резервное копирование
│   │   ├── rename.js    # Переименование файлов
│   │   ├── delete.js    # Удаление записи
│   │   ├── list.js      # Список всех записей
│   │   └── read.js      # Чтение записи
│   ├── streams/         # Работа с потоками
│   │   ├── read.js      # Чтение больших файлов
│   │   ├── write.js     # Запись данных
│   │   └── transform.js # Преобразование данных
│   ├── wt/              # Worker Threads
│   │   ├── spawn.js     # Запуск тяжелых операций
│   │   └── search_worker.js # Воркер для поиска
│   └── cli/             # CLI утилиты
│       └── search.js    # Интерактивный поиск
├── data/                # Директория для хранения данных
│   └── product_index.json # Индекс всех продуктов
├── server.js            # Express сервер
├── index.html           # Веб-интерфейс
├── products.json        # Данные о продуктах
├── orders.json          # Данные о заказах
└── package.json
```

## Установка

```bash
npm install
```

## Использование

### Файловая система (src/fs)

#### Создание новой записи
```bash
node src/fs/create.js "Название" "Категория" "Бренд" "Цена" ["Описание"]
```
Пример:
```bash
node src/fs/create.js "Электросамокат X1" "Электросамокаты" "Xiaomi" "15000" "Мощный самокат с дальностью 30км"
```

#### Список всех записей
```bash
node src/fs/list.js
```

#### Чтение записи
```bash
node src/fs/read.js <ID_продукта>
```
Пример:
```bash
node src/fs/read.js 1234567890
```

#### Удаление записи
```bash
node src/fs/delete.js <ID_продукта>
```
Пример:
```bash
node src/fs/delete.js 1234567890
```

#### Резервное копирование
```bash
node src/fs/copy.js <исходная_папка> <целевая_папка>
```
Пример:
```bash
node src/fs/copy.js ./data ./backup
```

#### Переименование файла
```bash
node src/fs/rename.js <старое_имя> <новое_имя>
```
Пример:
```bash
node src/fs/rename.js product_1234567890.json product_1234567890_fixed.json
```

### Потоки (src/streams)

#### Чтение большого файла
```bash
node src/streams/read.js <путь_к_файлу>
```
Пример:
```bash
node src/streams/read.js ../../data/product_index.json
```

#### Запись данных
```bash
node src/streams/write.js <путь_к_файлу> [данные...]
```
Пример:
```bash
node src/streams/write.js ../../data/catalog.txt "Продукт 1" "Продукт 2"
```

#### Преобразование данных
С файлами:
```bash
node src/streams/transform.js <входной_файл> <выходной_файл>
```

Из stdin:
```bash
echo '{"id":"1","name":"Test"}' | node src/streams/transform.js
```

### Worker Threads (src/wt)

#### Полнотекстовый поиск
```bash
node src/wt/spawn.js <поисковый_запрос>
```
Пример:
```bash
node src/wt/spawn.js "электросамокат"
```

### CLI утилиты

#### Интерактивный поиск
```bash
node src/cli/search.js
```
После запуска программа запросит критерий поиска.

## Формат данных

### Структура продукта
```json
{
  "id": "1234567890",
  "name": "Название продукта",
  "category": "Категория",
  "brand": "Бренд",
  "price": 15000,
  "description": "Описание",
  "createdAt": "2024-01-01T00:00:00.000Z"
}
```

### Индексный файл (product_index.json)
```json
[
  {
    "id": "1234567890",
    "name": "Название продукта",
    "category": "Категория",
    "brand": "Бренд",
    "price": 15000,
    "filename": "product_1234567890.json"
  }
]
```

## Особенности реализации

- **Уникальные ID**: Используется timestamp для генерации уникальных идентификаторов
- **Обработка ошибок**: Все операции включают обработку ошибок
- **Потоковая обработка**: Большие файлы обрабатываются по частям
- **Резервное копирование**: Рекурсивное копирование директорий
- **Интерактивный поиск**: CLI с запросом критериев поиска
- **Worker Threads**: Тяжелые операции выполняются в отдельных процессах

## Express Web-приложение

### Запуск сервера

```bash
npm install
npm start
```

Сервер будет доступен по адресу: `http://localhost:3000`

### API Endpoints

#### GET `/`
Возвращает веб-страницу с фронтенд-кодом (интерфейс магазина).

#### GET `/api/products`
Возвращает список всех продуктов в формате JSON.

**Пример ответа:**
```json
[
  {
    "id": "1",
    "name": "Электросамокат Xiaomi Mi Electric Scooter 4 Pro",
    "category": "Электросамокаты",
    "brand": "Xiaomi",
    "price": 45000,
    "stock": 15,
    "description": "Мощный электросамокат..."
  }
]
```

#### POST `/api/orders/refresh`
Возвращает обновленный список заказов в формате JSON.

#### POST `/api/orders`
Принимает данные нового заказа и создает его.

**Тело запроса:**
```json
{
  "productId": "1",
  "customerName": "Иван Иванов",
  "customerPhone": "+79001234567",
  "quantity": 2
}
```

**Обработка исключительных ситуаций:**
- Проверка заполнения всех обязательных полей
- Проверка существования продукта
- Проверка наличия товара на складе
- Проверка корректности количества

#### DELETE `/api/orders/:id`
Удаляет заказ по ID. При удалении ожидающего заказа товар возвращается на склад.

#### GET `/api/statistics`
Возвращает статистику магазина в формате, определяемом заголовком `Accept`:
- `application/json` или `*/*` - JSON формат (по умолчанию)
- `application/xml` или `text/xml` - XML формат
- `text/html` - HTML формат

**Пример использования:**
```bash
# JSON
curl http://localhost:3000/api/statistics

# XML
curl -H "Accept: application/xml" http://localhost:3000/api/statistics

# HTML
curl -H "Accept: text/html" http://localhost:3000/api/statistics
```

### Фронтенд функциональность

- **Каталог продуктов**: Отображение всех доступных продуктов с информацией о цене и остатках
- **Создание заказа**: Форма для создания нового заказа с валидацией
- **Список заказов**: Отображение всех заказов с возможностью удаления
- **Статистика**: Кнопки для скачивания статистики в форматах JSON, XML, HTML
- **Автоматическое обновление**: Данные обновляются после создания/удаления заказов

### Особенности реализации

- **Обработка исключений**: Все эндпоинты обрабатывают ошибки и возвращают понятные сообщения
- **Устойчивость к изменениям файлов**: Приложение продолжает работать при изменении JSON файлов
- **Валидация данных**: Проверка всех входящих данных перед обработкой
- **Управление складом**: Автоматическое уменьшение/увеличение остатков при создании/удалении заказов
- **Content Negotiation**: Поддержка разных форматов ответа на основе заголовка Accept
