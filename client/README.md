# Клиентская часть - Подписные издания

React приложение для управления подписными изданиями.

## Технологии

- React 18
- Redux Toolkit
- React Router
- Axios
- Vite
- React Toastify

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

## Сборка для продакшена

```bash
npm run build
```

## Структура проекта

```
client/
├── src/
│   ├── components/          # React компоненты
│   │   ├── Layout/          # Компонент макета
│   │   ├── Modal/           # Модальные окна
│   │   ├── ConfirmModal/    # Модальное окно подтверждения
│   │   ├── Publications/    # Компоненты для изданий
│   │   ├── Recipients/      # Компоненты для получателей
│   │   └── Subscriptions/   # Компоненты для подписок
│   ├── pages/               # Страницы приложения
│   ├── store/               # Redux store
│   │   └── slices/          # Redux slices
│   ├── services/            # API сервисы (Axios)
│   ├── utils/               # Утилиты
│   ├── styles/              # Общие стили
│   ├── App.jsx              # Главный компонент
│   └── index.jsx            # Точка входа
├── package.json
└── vite.config.js
```

## Основные возможности

- ✅ Адаптивный интерфейс
- ✅ Redux для управления состоянием
- ✅ Роутинг между страницами
- ✅ CRUD операции для всех сущностей
- ✅ Валидация форм
- ✅ Подтверждение удаления
- ✅ Детальный просмотр с фото
- ✅ Загрузка изображений
- ✅ Пагинация, сортировка, фильтрация
- ✅ Поиск по нескольким полям

## API

Приложение использует API сервера, который должен быть запущен на `http://localhost:5000`.

Прокси настроен в `vite.config.js` для автоматической переадресации запросов к `/api` на сервер.
