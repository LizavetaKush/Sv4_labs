# Скрипты для работы с базой данных

## createDatabase.js

Создает базу данных PostgreSQL, если она не существует.

**Использование:**
```bash
npm run db:create
```

## seed.js

Заполняет базу данных тестовыми данными через Sequelize.

**Использование:**
```bash
npm run db:seed
```

**Создает:**
- 18 изданий (газеты и журналы)
- 17 получателей
- 20 подписок

**Всего: 55 записей**

## seed.sql

SQL скрипт для заполнения базы данных тестовыми данными.

**Использование:**
```bash
psql -U postgres -d subscription_publications -f server/scripts/seed.sql
```

Или через любой SQL клиент (pgAdmin, DBeaver и т.д.)

**Примечание:** Скрипт очищает существующие данные перед вставкой новых.
