# Исходные данные для заполнения базы данных

Эта папка содержит JSON-файлы с тестовыми данными для заполнения базы данных.

## Файлы

### publications.json
Содержит данные об изданиях (газетах и журналах):
- `index` - индекс издания (уникальный)
- `type` - вид издания ("газета" или "журнал")
- `title` - название издания
- `monthlyPrice` - стоимость подписки на месяц в рублях

**Количество записей:** 15

### recipients.json
Содержит данные о получателях:
- `code` - код получателя (уникальный)
- `fullName` - Ф.И.О. получателя
- `address` - объект с адресом:
  - `street` - улица
  - `house` - номер дома
  - `apartment` - номер квартиры

**Количество записей:** 20

### subscriptions.json
Содержит данные о подписках:
- `recipientCode` - код получателя (должен существовать в recipients.json)
- `publicationIndex` - индекс издания (должен существовать в publications.json)
- `duration` - срок подписки в месяцах (1, 3 или 6)
- `startMonth` - месяц начала доставки (1-12)
- `startYear` - год начала доставки

**Количество записей:** 32

## Использование

Для заполнения базы данных используйте команду:

```bash
npm run seed
```

Или с очисткой существующих данных:

```bash
npm run seed:clear
```

## Примечания

- Скрипт автоматически проверяет существование записей и не создает дубликаты
- При загрузке подписок проверяется существование получателей и изданий
- Если получатель или издание не найдены, подписка будет пропущена с предупреждением
- Вы можете редактировать эти файлы для добавления своих данных
- **Общее количество записей:** 67 (15 + 20 + 32)
